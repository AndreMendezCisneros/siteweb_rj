# RYJEC — Sitio corporativo

Sitio web de RYJEC (Next.js + Tailwind CSS + TypeScript).

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — build de producción
- `npm run start` — servir build
- `npm run lint` — ESLint

## Estructura

- `src/app` — rutas y páginas
- `src/components` — UI y layout
- `src/content/site.ts` — copy y datos de marca
- `src/lib` — utilidades (catálogo de soluciones)
